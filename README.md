# Rozetka Face Blurring

[![Python](https://img.shields.io/badge/Python-3.7%2B-blue)]()\
[![OpenCV](https://img.shields.io/badge/OpenCV-4.x-red)]()\
[![MediaPipe](https://img.shields.io/badge/MediaPipe-Face_Detection-orange)]()

Небольшой утилитарный скрипт, который в реальном времени размывает лицо
с веб-камеры. Использует MediaPipe для детекции и OpenCV для обработки
изображения. Подходит как основа для проектов, где нужно скрывать лицо
или частично анонимизировать потоковое видео.

## 📌 Особенности

-   Реальное время (обработка происходит на лету).
-   Простая и надёжная детекция лица через MediaPipe.
-   Локальная работа --- изображение никуда не отправляется.
-   Минимальные зависимости и простой код.

## 🚀 Как работает

Каждый кадр с веб-камеры проходит следующие шаги:

1.  Захват видеопотока через `cv2.VideoCapture`.
2.  Детекция лица (MediaPipe Face Detection).
3.  Выделение bounding box лица.
4.  Применение Gaussian Blur к этой области.
5.  Отображение результата в отдельном окне.
6.  Завершение по клавише **`q`**.

## 🛠 Установка

### Требования

-   **Python 3.7+**
-   Веб-камера

### Установка зависимостей

``` bash
pip install opencv-python mediapipe
```

## ▶ Запуск

``` bash
python rozetka_face_blurring.py
```

## ⚠ Важные замечания

-   Для корректной работы желательно нормальное освещение.
-   Если камера даёт низкий FPS, блюр может казаться «рывками».
-   Работает только с **локальной камерой** --- IP-камера не
    поддерживается.
-   Производительность зависит от мощности CPU, т.к. обработка идёт на
    процессоре.
